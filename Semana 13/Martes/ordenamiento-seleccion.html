Programación I · Ordenamiento de vectores

Ordenamiento por selección

Para cada posición del vector, buscá el menor de los valores que todavía no están ordenados y llevalo a esa posición con un intercambio.

Repetís eso de izquierda a derecha. Cada vuelta deja un elemento más en su lugar definitivo, así que la parte ordenada crece de a uno hasta cubrir todo el vector.

01

La idea en tres movimientos

1

Elegir el lugar

Fijás una posición i: es el casillero que vas a completar en esta pasada. Arranca en 0.

2

Buscar el menor

Recorrés con j desde i+1 hasta el final, y guardás en posMin la posición del valor más chico que vas encontrando.

3

Intercambiar

Cambiás v[i] con v[posMin]. El menor queda en la posición i y ya no se vuelve a tocar.

02

Paso a paso con un ejemplo

Ordenamos de menor a mayor el vector {29, 10, 14, 37, 13}. Cada fila muestra el vector antes del intercambio de esa pasada.

04

El intercambio necesita una auxiliar

Si hacés v[i] = v[posMin]; directamente, el operador de asignación pisa el valor que había en v[i] y se pierde. Por eso primero se guarda una copia en aux. Ejemplo de la pasada 1: i = 0, posMin = 1.

aux = v[i];

Se guarda una copia del 29.

v[i] = v[posMin];

aux

El menor pasa a la posición i. Por un momento el 10 está dos veces.

v[posMin] = aux;

v[1]
29
aux

El 29 vuelve al vector, en el lugar que dejó el menor.

05

Código y diagrama de flujo

El programa completo que ordena el vector del ejemplo y lo muestra, junto con su diagrama de flujo.

/**
   Ordenamiento por selección.
   Ordena de menor a mayor un vector de 5 enteros y lo muestra.

   DE: vector de enteros (cargado en el programa)
   DS: vector ordenado de menor a mayor
   Estrategia: para cada posición i, buscar la posición del menor
   entre i y el final, e intercambiarlo con v[i].
*/
#include <iostream>
using namespace std;

int main(){
   const int TAM = 5;
   int v[TAM] = {29, 10, 14, 37, 13};
   int i, j, posMin, aux;

   /// Ordenamiento
   for(i=0; i<TAM-1; i++){
      posMin = i;
      for(j=i+1; j<TAM; j++){
         if(v[j] < v[posMin]){
            posMin = j;
         }
      }
      aux = v[i];
      v[i] = v[posMin];
      v[posMin] = aux;
   }

   /// Muestra del vector ordenado
   cout << "Vector ordenado: ";
   for(i=0; i<TAM; i++){
      cout << v[i] << " ";
   }
   cout << endl;

   return 0;
}
