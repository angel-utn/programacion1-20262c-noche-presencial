Programación I · Ordenamiento de vectores

Ordenamiento por burbujeo

Recorré el vector comparando cada elemento con el siguiente y, si están al revés, intercambialos.

En cada recorrido completo (una pasada) el mayor de la zona sin ordenar va subiendo hasta el final, como una burbuja. Así la parte ordenada crece de a uno desde la derecha.

01

La idea en tres movimientos

1

Comparar vecinos

Mirás un par de elementos contiguos: v[j] y v[j+1]. El recorrido arranca con j en 0.

2

Intercambiar si están al revés

Si v[j] > v[j+1], el mayor está antes que el menor: los intercambiás. Si no, quedan como están.

3

Avanzar al próximo par

j avanza una posición y se repite. Al terminar la pasada, el mayor quedó al final y la siguiente pasada recorre un par menos.

02

Paso a paso con un ejemplo

Ordenamos de menor a mayor el vector {29, 10, 14, 37, 13}. Cada fila muestra el vector en el momento de comparar el par marcado.

04

El intercambio necesita una auxiliar

Si hacés v[j] = v[j+1]; directamente, el operador de asignación pisa el valor que había en v[j] y se pierde. Por eso primero se guarda una copia en aux. Ejemplo de la primera comparación: j = 0.

aux = v[j];

05

Código y diagrama de flujo

El programa completo que ordena el vector del ejemplo y lo muestra, junto con su diagrama de flujo.

/**
   Ordenamiento por burbujeo.
   Ordena de menor a mayor un vector de 5 enteros y lo muestra.

   DE: vector de enteros (cargado en el programa)
   DS: vector ordenado de menor a mayor
   Estrategia: recorrer el vector comparando cada elemento con el
   siguiente e intercambiarlos si están al revés. En cada pasada el
   mayor de la zona sin ordenar queda al final.
*/
#include <iostream>
using namespace std;

int main(){
   const int TAM = 5;
   int v[TAM] = {29, 10, 14, 37, 13};
   int i, j, aux;

   /// Ordenamiento
   for(i=0; i<TAM-1; i++){
      for(j=0; j<TAM-1-i; j++){
         if(v[j] > v[j+1]){
            aux = v[j];
            v[j] = v[j+1];
            v[j+1] = aux;
         }
      }
   }

   /// Muestra del vector ordenado
   cout << "Vector ordenado: ";
   for(i=0; i<TAM; i++){
      cout << v[i] << " ";
   }
   cout << endl;

   return 0;
}
